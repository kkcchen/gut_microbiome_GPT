files we need for train generator/discriminator:
- train_dataset, npy, (num_samples, num_bacteria, 2), they truncated num_bacteria to 512, the last 2 dims are (embedding_id, frequency/abundance)
- test_dataset, same as train dataset
- vocab_path, npy, (num_bacteria, embedding_dim=100 for them), they used deepmicro for this, we need metadata and a whole bunch of things to use deepmicro tho
    - im just using clip for bacteria name right now

dataset setup:
- each item is originally (512, 2), which first dim representing bacteria id and second dim representing relative abundance
- sort by abundance
- apply cls token so things are (513, 2)
- seperate the two dims, only the first dim is used for training as input
- the labels are the ground truth bacteria index
- a mask tensor of shape (513) is also returned, boolean

hmc contains 4850 samples from american gut project (PRJEB11419)
